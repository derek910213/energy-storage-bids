# 储能招标信息采集脚本

从公开招标信息平台采集储能相关项目的招标 / 中标结果信息，包括项目标的、中标单位、中标金额、候选单位等字段。

- 抓取的数据来源于目标网站的公开信息，使用前请自行确认符合目标网站的用户协议与相关法律法规。
- 请**合理控制访问频率**，不要对目标网站造成过大压力；因不当使用造成的任何后果，使用者自行承担。
- 目标网站的页面结构可能随时改版，脚本中的选择器 / 接口参数需要定期核对维护，不保证长期可用。

## 脚本一：dnezb_spider.py（电力能源招标网）

**功能**：按关键词（默认"储能"）搜索，筛选近 1 年内的"中标结果"类信息，提取标题、发布日期、中标单位、中标金额、原文链接，导出 CSV。

**运行**：

```bash
python dnezb_spider.py
```

**输出**：`储能招标中标信息.csv`

**已知限制**：
- 脚本中标注 `[需核对]` 的 CSS 选择器（列表容器、分页参数名、详情页正文容器）是根据同类网站通用结构写的模板，实际结构请用浏览器开发者工具（F12）核对后调整。
- 目标站点存在限流（429），脚本已内置退避重试，但仍可能被拦截，请勿调低默认的请求间隔。

## 脚本二：cebpubservice_spider.py（中国招标投标公共服务平台）

**功能**：抓取【中标结果公示】【中标候选人公示】两个栏目，用标题关键词过滤储能相关项目，提取项目标的、中标单位、中标金额、候选单位、发布日期、所属行业/地区等字段，导出 CSV。

**运行**：

```bash
python cebpubservice_spider.py
```

**输出**：`储能招标中标信息_中国招标投标公共服务平台.csv`

**已知限制**：
- 生产站对直接 GET 请求可能返回 405，说明页面内容很可能由前端 JS 异步渲染。若 requests 方案跑不通，请改用脚本文件末尾注释掉的 Selenium 备用方案（`crawl_with_selenium`）。
- 站内未找到全站关键词搜索接口，脚本采用"栏目翻页 + 标题关键词过滤"的方式，效率有限，数据量较大的栏目建议先用小的 `MAX_PAGES_PER_CATEGORY` 测试。
- "中标金额" "中标单位" "候选单位" 的正则提取基于常见表述编写，不同地方交易平台措辞差异较大，无法保证 100% 覆盖，建议先跑一小批数据检查提取效果，再针对性调整正则表达式。

## 使用建议

1. 首次运行前，先把 `MAX_PAGES` / `MAX_PAGES_PER_CATEGORY` 调小（如 2），确认能正常抓到数据、字段提取效果符合预期后，再放开跑全量。
2. 不建议设置为高频定时任务对网站进行全量轮询采集。
3. 抓取结果 CSV 可能包含企业名称等信息，请注意妥善保管，不建议随代码一并公开分发（见 `.gitignore`）。
